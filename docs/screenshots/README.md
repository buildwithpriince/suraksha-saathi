# Screenshots

The root README shows these files in a 3 × 3 grid, 220 px wide. Save them here with exactly these
names. PNGs go through Git LFS (`.gitattributes`); GitHub renders them in the README.

| File | What to capture |
|---|---|
| `home.png` | Home with a few workers, one "Refresher due" badge, the language picker |
| `fire-drill.png` | FIRE_01 in camera mode: fire on the real floor, step card, EXIT marker or route arrow |
| `extinguisher.png` | The extinguisher step while spraying: ring on the base of the fire, fire level shrinking |
| `result.png` | Result screen after a pass, with rule rows and the score |
| `certificate.png` | Certificate screen with the wallet card and the full-width QR |
| `verify.png` | Verify screen showing a green **Valid** result |
| `id-card.png` | Worker ID wallet card with photo and login QR |
| `dashboard-overview.png` | Dashboard overview (compliance numbers and heatmap), desktop width |
| `retention-chart.png` | Dashboard refresher retention chart |

Phone shots: portrait, from a real phone, status bar clean. Keep each file under about 500 KB.
